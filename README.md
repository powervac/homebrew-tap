# Homebrew tap of Alternate Commander

[Alternate Commander](https://altcom.cc) - a free, open-source two-panel file manager for Windows, macOS and Linux.

```
brew install --cask powervac/tap/alternate-commander
```

The app is not signed by Apple: the cask removes the quarantine mark and signs it locally after the installation.
Releases: https://github.com/powervac/Alternate-Total-Commander/releases
